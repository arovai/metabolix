# Source Notes Summary

The source notes specify `metabolix`, a pip-installable CLI BIDS app for all-voxel processing of already-converted image-space multi-voxel proton MRSI using FSL-MRS. It must support subject/session/acquisition/run selection, YAML with explicit CLI precedence, participant processing, and group aggregation of existing participant results.

The example is GE PROBE-P/PRESS near 3 T, TE 144 ms, TR 1 s, typically 22 x 22 x 1 x 1024 x 32 with tagged `DIM_COIL`, 0.25 ms dwell, 4 kHz bandwidth, and a 127.770515 MHz frequency. Geometry/coils/slice thickness vary; metadata must be read, not hard-coded. A user-provided MRSCloud basis is documented with 16 components, 127.731 MHz, 4 kHz, 8192 points and SHA256 `06b4c2a4b711e6250a42bc88bae0c1f44b80cf32e4ba9f8334035a4ccd9a318b`; it is an example candidate, not universally validated. The MATLAB `_wMM` file has MM/lipid components absent from the `.BASIS` export. No separate unsuppressed-water reference is identified.

All spatial voxels are default. Coil combination is tag-driven; residual water removal is off/on/compare and never chosen from a peak ratio. Fits require an explicit compatible basis and default to internal-reference ratios, not absolute concentration. Optional FreeSurfer/arbitrary ROI overlap is nominal geometry using scanner/world affine sampling, full-voxel denominator, <=0.5 mm plus 1 mm sensitivity comparison and separate field-of-view coverage. Anatomy overlap never restricts fitting by default.

Important QC caveats: FSL Newton `*_sd` maps are percentage CRLB estimates, potentially capped at 999%, not absolute SD or fully propagated ratio uncertainty; zero reference yields undefined ratios; outside-mask zeros are not observations; a standard aggregate FSL report does not represent independent voxel fits; NIfTI-MRS/FSL complex conventions differ. Preserve native FSL outputs and export invalid ratios as missing with reasons.

Reference scripts and `PROCESSING_LOG.md` describe exploratory work, including a four-voxel pilot, early coil combine and water-removal checks, generic-basis caveats and later MRSCloud basis inspection. The pilot restriction is explicitly superseded. Reported commands/results are historical, not reproduced here. No whole-dataset processing is authorized. FSL-MRS official documentation recommends the FSL installer or Conda; the wrapper may be pip installed but does not install FSL implicitly.
